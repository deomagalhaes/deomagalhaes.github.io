📱 Abrir ou Instalar no Celular

Aponte a câmera do celular

https://deomagalhaes.com.br/bonsai/

No Android (Chrome): toque no menu ⋮ → Adicionar à tela inicial / Instalar aplicativo.
No iPhone (Safari): toque em Compartilhar → Adicionar à Tela de Início.

📦 Como gerar o arquivo .APK grátis

Gerar APK nativo em 2 minutos (Sem instalar nada no PC)

  1. Após publicar esta pasta no GitHub Pages, acesse pwabuilder.com no navegador.
  2. Cole o endereço https://deomagalhaes.com.br/bonsai/ e clique em Start.
  3. Clique em Package for stores → Android → Generate Package.
  4. Baixe o pacote ZIP gratuito: dentro dele já virá o arquivo Bonsai Mori.apk assinado e pronto para instalar ou disponibilizar no GitHub Releases!
